### Deeper materialization diagnosis

The current materializer still assumes one local sheet per authoritative cell. `normalize_scope()` assigns `cell.sourceSheet = -1` when a topology-region cell carries multiple `sourceIsolationSheets`; `build_authoritative_phase_front_mesh()` rejects any cell with `cell.sourceSheet < 0` and keys periodic/lattice materialization by `(component, sheet, lattice)`. This is incompatible with a legitimate topology region that crosses an internal isolation seam.

The next implementation architecture must therefore make authoritative phase-front materialization topology-region aware while preserving exact per-corner/local-isolation provenance. It must not erase local sheet identity or weld by position.
