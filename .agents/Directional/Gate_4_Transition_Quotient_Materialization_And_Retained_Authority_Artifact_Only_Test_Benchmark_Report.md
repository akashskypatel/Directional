## Failure classification

### Failure 1 — genuine source-boundary authority is unrepresentable

- Classification: **product implementation regression**.
- Evidence: all four accepted direct baselines and broad producer groups stop at `InvalidFrontBoundaryAuthority`.
- Contract: a one-face source edge is a genuine exterior boundary and must carry exact topology authority without being mistaken for an interior transition.
- Source-bounded root cause: `assign_open_front_boundary_authority()` obtains `sourceEdgeIndices` from `edge_matching_indices()`. That table intentionally includes only source edges with two incident faces. The classifier nevertheless requires `foundIndex != end` before it checks `foundIncident->second[1] < 0` and classifies a genuine source boundary. Every legitimate one-face boundary route is therefore rejected by construction.

This is not a tolerance, fixture, field, or infrastructure problem. The next design must distinguish canonical source-edge topology identity from the optional interior matching/transition index.

### Failure 2 — isolation-seam consumption ownership remains unresolved

- Classification: **product/contract design blocker**.
- Evidence: torus phase-front is `Produced`, then rejects with all 4 regions, 8 seams, and 4 relations unconsumed.
- Contract: a multi-isolation topology region must materialize without selecting one representative sheet, while exact seam transport and local-isolation lineage remain complete.
- Source-bounded cause: the materializer constructs `consumedTransitionTopology` only from `SurfaceTraceSegment.transitionSourceEdges` on cell boundary paths, then requires every `region.internalIsolationSeamTopology` edge to appear in that set. Artifact evidence does not prove that every internal seam must cross a cell boundary path or that this one representation is complete. The first missing seam aborts before any quotient-consumption counters commit.

Independent review must decide the exact consumption witness: cell-side transition ownership, occurrence-equivalence provenance, region coverage, or a stronger combination. The invariant may not be bypassed or satisfied by counts, IDs, proximity, or unconditional marking.

### Failure 3 — required counterfactual tests are not executable

- Classification: **build/test packaging and coverage defect**.
- Evidence: packaged discovery lists five executables and no historical test target; the two semantic-digest tests are in a target disabled by configuration.
- Contract: permutation invariance and connectivity/lineage sensitivity, plus every reviewed quotient/retention counterfactual, must execute from the immutable artifact.
- Likely root cause: tests were added to a superseded historical file without enabling or moving them into a default packaged target; other required groups were not implemented as independently discoverable tests.

### Failure 4 — retention iff contract has only positive evidence

- Classification: **partial evidence / missing focused test**.
- Evidence: the torus producer test proves `hasTraceNetwork=true` when retention is requested, but no packaged `retainIntermediateGeometry=false` counterpart exists.
- Contract: pre-materialization failure retains the trace network if and only if requested.
