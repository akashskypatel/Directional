Let N be occurrence count, K number of non-empty quotient classes, R number of owned relations, F=N−K joining edges, C=R−F cycle-closing relations (complete valid production). Let F_i be the number of joining edges already present at cycle closure i, and L the sum of lengths of root-to-member paths over all classes. These are symbolic counts; no values for row1006 were measured. Each current call inserts two directed entries per forest edge and sorts its adjacency. Producer call count is C+F=R, with `2*sum(F_i)+2*F*F` directed insertions. Publication adds C+F calls over the final forest (`2*R*F` insertions). The verifier adds F path calls (`2*F*F`). Total across these three stages on a complete valid path: `2*(sum(F_i)+R*F+2*F*F)` directed insertions, plus map lookup, sorting, destruction, local traversal and output construction. For early exits or malformed records these identities are not guaranteed. This cost is quadratic in forest size even when every class is a two-member pair, and it includes unrelated components. A single query creates storage proportional to the entire forest. The five calls are the complete helper-use inventory in the source. Only the producer's two calls are sampled; later stage costs are static findings, not observed bottlenecks.

A path-shaped class rooted at an end has n_j*(n_j−1)/2 path steps. Selected hard-rail/periodic paths also store the ordered projected steps and source support; nested payload cost is in addition to these counts. A7 indexes by full class IDs and copies legacy projections (7323, 7658–7696); verifier maps and checks full IDs.
