## 2. Conservative admissibility contract

The scheduling quotient is a partition of **Mandatory A2b arcs**, never a change to the A2b graph, its nodes, or region boundary occurrences. Trace/Cut arcs are outside this partition. A pair of directed adjacent Mandatory children may join only if all of these are independently certified:

1. They meet at the same canonical *topological* endpoint under source-entity/chart transitions (not close coordinates, equal source-face row, or matching hashes); they are consecutive in every incident region's oriented boundary walk.
2. Exactly one incoming and one outgoing eligible Mandatory arc continue at that node in the relevant oriented source-sheet fan. No Trace/Cut arc, port, feature corner, hard-rail endpoint, barrier, branching, boundary ownership change, or ambiguous fan intervenes. Ordinary source-edge vertices are **not** barriers solely because they divide the triangulation; any separately protected source vertex still is.
3. The children have the same ordered incident ownership pair: either two distinct regions traversing them in opposite surface directions, or one region and its component-local exterior. A two-occurrence/same-region self-loop, although permitted by the old baseline degree check, is **not** a quotient candidate until a separate loop-incidence proof exists; keep it as original singleton arc(s).
4. Their exact source-support pieces are individually valid, nonzero and concatenate into one intrinsic path with no gap, overlap or branch. Each original `NetworkArcId`, mandatory-edge ID, original source-support interval, oriented boundary occurrence `(region, ordinal, direction)`, component and sheet must be reconstructible exactly after scheduling.

Maximality is deterministic closure under these certified pairwise joins, **not** a demand to merge past an unknown predicate. If a join's proof is missing or contradictory, preserve its children as separate scheduling units and record a typed non-eligibility reason; do not silently equate source vertices by position. A wholly closed Mandatory cycle with no certified cut is not silently turned into an open span: retain original arcs until a separately certified cyclic-unit scheme exists. Avoid inventing a canonical seam by source-face row index.

## 3. Unit count and breakpoint expansion

For chain `C = (a_0,...,a_(k-1))`, form an ordered path retaining original carriers and signed child maps. Run D7's canonical direction-run metric over **that physical path**, not the prior per-arc preferred counts. D7b allocates a *strictly positive count to the unit* and uses positive ceiling-weight runs, exact rational run interpolation and canonical reversal. Because `n_C` may be less than `k`, a child arc is allowed zero **interior** chain breakpoints; this is not a zero-length child, a zero-valued original scheduled span, or an omitted source segment. Map each unit subdivision's two exact endpoints and its ordered (possibly multi-piece and multi-child) carrier walk into the immutable original source topology.

Represent an interval that crosses a child join as **one** unit interval with an ordered multi-child exact source-support walk, never a separate phantom quad edge on each child. At each internal join, use a canonical half-open ownership convention for the point, but retain both original adjacent support incidences as provenance; reversal must map unit ordinal `j` to `n_C-j` and reverse the full child/interval walk. Validate complete interval coverage of every child (including a child with no interior breakpoint) before A4 consumes anything.

## 4. Parity equivalence: what must actually be proved

The existing algorithm constructs a region-to-span graph with one or two boundary occurrences per span and solves an exact minimum-cardinality parity correction. A chain unit may replace several columns only when *every original member* carries the same two **distinct** regional endpoints (or the same region/exterior), with a complete uninterrupted oriented occurrence walk on each side. Then every unit interval occurs once on each incident region, with opposite orientation where there are two sides. Consequently each affected region's expanded boundary edge count receives `n_C` unit intervals exactly once; this is the parity coefficient `1` of the quotient column. Region parity is computed from the **expanded** boundary interval inventory, not by summing a deprecated per-child preferred count or by trusting only a graph digest. A two-sided occurrence in the same region, duplicated region visits, or a partial region traversal makes that argument invalid and is excluded by the conservative contract.

The independent certificate verifier must independently derive the quotient from immutable source/network/topology authority, compare original child partitions and all exact source supports/ordered occurrences, expand every scheduled interval back to `(unit, child, source support, region occurrence, direction)`, verify each interval has exactly the required incidences, and rederive each region's parity. Only then may the unchanged exact T-join + lex-prefix rule run on the quotient graph. A constructor and verifier sharing the same unchecked quotient digest or inferred ownership are not independent proof.
