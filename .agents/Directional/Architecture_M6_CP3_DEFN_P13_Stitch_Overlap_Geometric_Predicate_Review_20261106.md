- The original Vase OFF source's bounding-box diagonal is **2.0119413889380575**. The default `SourceAuthoritativeMeshValidatorOptions.geometricTolerance` is `1e-9`; thus its computed length tolerance at `SourceAuthoritativeMeshValidator.cpp:1138` is **6.438212444601785e-8**.

The full quad polygons also have zero projected intersection area and distance approximately **4.514559319749602e-5** in XY.
- Yet the legacy `collinear_segment_overlap2` uses `abs(orient2(a,b,c)) <= tolerance` and `abs(orient2(a,b,d)) <= tolerance`: on triangle edges `(firstEdge=1,secondEdge=1)`, the orientation determinants are `1.637496283580536e-8` and `1.6374962835681214e-8`, while projected coordinate intervals overlap by **0.00023999081517067644**. Therefore the function returns true **despite the physical gap**, since it compares determinant units (length squared) to a length threshold without scaling by edge length. On the first edge, the true perpendicular separation is about **5.716621019919155e-5**. This is a falsifiable geometric *false positive*, not verified overlapping completed patches.
