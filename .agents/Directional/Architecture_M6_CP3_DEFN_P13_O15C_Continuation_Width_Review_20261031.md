## 2. Mathematical and architectural ruling

**Reject increasing the cap:** any fixed cap permits only a finite path length under repeated rational composition, and a 4096-to-larger replacement simply defers the failure; no finite cap provides a trace-length-independent width proof. **Reject one-time rounded directions:** it may lower the per-step growth constant, but the exact rational exit compositions still accumulate distinct denominator factors, so it does not bound the width as continuation length grows. A bare `double` round-trip additionally contradicts DESIGN Amendments 18 and 20 and RA-176/RA-180 exactness.

**Elect a canonical dyadic exit product at each face boundary:** A2a computes each local *proposed* exit and its outgoing-carrier/vertex election with exact rational predicates, then constructs the **published** next entry as an explicitly named canonical grid representative. For an interior outgoing-edge parameter `t` in (0,1), let `B=52`, `n = nearest_integer_ties_to_even(2^B t)` using only exact integer quotient/remainder operations, and publish `q=n/2^B`. An exact vertex hit remains exactly 0 or 1; rounding must never silently create a vertex hit or suppress a true vertex hit. If `0<n<2^B` fails for an exact interior exit, reject with a new typed `ContinuationDyadicEndpointCollapse`, preserving the original face/edge/branch locus. The same undirected canonical source-edge parameter orientation is used in both incident faces. This is *not* asserted to reproduce the unchanged exact integral curve.

**Why this is bounded:** each published interior parameter has reduced numerator and denominator of at most **53 bits**, independently of the number of crossed faces. If each current face's exact direction components have numerator/denominator magnitudes ≤ D bits, computing the next exact *proposed* exit from a 53-bit entry requires a bounded number of rational arithmetic operations; their intermediate bit size has a conservative `O(53 + cD)` local bound independent of prior trace length. A pre-arithmetic guard must certify the actual input direction and temporary-operation budget before expensive expansion; exceeding it fails closed. `B=52` is a fixed, source-edge-relative policy, chosen to retain binary64-significand-scale fractional resolution, **not** an empirically calibrated accuracy guarantee. The exact rounding displacement along an exit edge is ≤ `2^-53 * edge_length`. No cumulative error or cross-platform topology equivalence follows from this local displacement bound alone.

**Required semantic amendment (narrow):** DESIGN Amendment 18 forbids snapping an existing exact coordinate, and Amendment 20 permits input conditioning only at the boundary. This new primitive is allowed **only as the definition of a newly constructed A2a exit**, not as mutation of an A0/A1 value or a correction to an already-published A2a trace. The unrounded candidate is ephemeral diagnostic/proposal data; the dyadic exit is the single authoritative emitted output with a versioned policy, exact grid coordinate and round-direction receipt. Its geometry is a **bounded dyadic approximation**, not an exact representative of the unmodified field integral curve. A production output may only claim strict success if all existing network, rail, phase, source-support, sheet, exact-topology and final validators remain satisfied, and an additional *certified* local field-alignment/deviation contract is met. Geometric quality bounds must not decide topological membership. No floating arithmetic is allowed in the election, rounding, transition, intersection or ordering predicates.

**Safety before publication:** Validate exact barycentric range, positive-length segment, intended outgoing-carrier order/flow, no barrier crossing, no sheet/component change, and correct canonical edge orientation on *rounded* geometry. Near a vertex, rail, intersecting trace, or tie where the rounded candidate could lose required separation or alter protected ownership, require a pre-committed exact separation/adjacency certificate or reject with a typed quantization ambiguity; do not silently choose a different branch, snap to a hard feature, or turn a non-hit into a hit. Contact/overlap/loop detection uses exact arithmetic on the published dyadic state; never reuse the old exact-trajectory classification after rounding. Preserve preexisting 4096-bit fail-closed guard for local arithmetic whose source-direction complexity still exceeds the declared budget. The independent product oracle must reject a dyadic-output certificate missing its policy version/point provenance.

**Scope boundary:** Source geometry/field remain bit-preserving; no change to A1, Amendments 15/22/23, or to the independent exact topology predicates. No silent fallback to approximate topology, no unproved equivalence to old exact trace, no redistribution of singularity indices, no changing fixture expectations or validator strength. A future Review must adjudicate evidence if a formerly admissible strict trace fails because of quantization; the implementation may not hide that cost by tuning B or changing the oracle after viewing TB64.
